Another site

This page is not served by the shop. You host it yourself so the request to the shop is cross-site.

How to open this file

  • Open it directly (file://…/cross-site.html), or
  • Serve this folder from another origin, e.g. python3 -m http.server 8080 then http://127.0.0.1:8080/cross-site.html.

Sign in on the shop at http://localhost:3001 first. Use the same shop URL in the form below.

The button sends a cross-site POST with no JavaScript. The response loads in a hidden frame; check /members on the shop tab.
